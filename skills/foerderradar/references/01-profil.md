# Schritt 1: Organisation analysieren

Ziel: ein Förderprofil, aus dem sich Passung und Antragsberechtigung ablesen lassen.

## Quellen, in dieser Reihenfolge

1. Dateien im Arbeitsordner: Satzung, Freistellungsbescheid (oder Feststellungsbescheid nach § 60a AO), Vereinsregisterauszug, Jahresbericht, Haushalts- oder Wirtschaftsplan, Protokolle, Projektskizzen. Suche mit Glob nach `*.pdf`, `*.docx`, `*.md` und lies, was nach diesen Dokumenten aussieht.
2. Die Website der Organisation: Startseite, „Über uns“, „Projekte“, Impressum. Frag nach der Adresse, wenn sie nicht im Ordner steht.
3. Erst dann fragen, und nur nach dem, was fehlt und für Förderung zählt. Höchstens fünf Fragen auf einmal.

## Vorlage `foerderung/profil.md`

```markdown
# Förderprofil: <Name>
Stand: <Datum> · Quellen: <Dateien und URLs>

## Eckdaten
| | |
|---|---|
| Rechtsform | e.V. / gGmbH / Stiftung / Initiative ohne Rechtsform |
| Sitz | <Ort>, <Kreis>, Bundesland-Kürzel <BB> |
| Gegründet | <Jahr> (wichtig für Mindest-Bestandsdauer) |
| Gemeinnützig | ja/nein · Bescheid vom <Datum> · Finanzamt <Ort> |
| Steuerbegünstigte Zwecke | laut Satzung, mit Nummer aus § 52 AO wenn möglich |
| Mitglieder / Aktive | |
| Jahresbudget ungefähr | |
| Eigenmittel für Eigenanteil | ja, bis ca. <Betrag> / nein |
| Vorfinanzierung möglich | ja/nein (viele Programme zahlen erst nachträglich) |
| Ansprechperson für Anträge | Rolle, nicht Privatadresse |

## Was die Organisation tut
3–5 Sätze in Alltagssprache.

## Zielgruppen
## Themenfelder (Stichworte für die Suche)
## Geplante Vorhaben und Bedarfe
Je Vorhaben: Was, für wen, ab wann, grob wie teuer.

## Offene Punkte
Was nicht belegt ist und nachgeliefert werden muss.
```

## Achte auf

- Fehlt ein Freistellungsbescheid oder ist er älter als drei Jahre (Körperschaftsteuer) bzw. fünf Jahre: in „Offene Punkte“ aufnehmen. Viele Förderer verlangen einen aktuellen Bescheid.
- Satzungszwecke entscheiden über Förderfähigkeit. Ein Projekt außerhalb der Satzungszwecke ist ein Risiko, auch wenn das Programm passt.
- Das Bundesland-Kürzel braucht Schritt 2: BW, BY, BE, BB, HB, HH, HE, MV, NI, NW, RP, SL, SN, ST, SH, TH.
